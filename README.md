# 바이브코딩 개발 가이드

비전공 교사와 초보 개발자를 위한 바이브코딩 웹앱 개발 안내 사이트입니다.

## 사이트 기능

- 프론트엔드·백엔드 동작 시뮬레이션
- 초보자용 쉬운 7단계 개발 과정
- 생성형 AI와 문답하며 개발하는 과정
- 교육용 JavaScript 라이브러리 모음
- 프롬프트 복사
- 프로젝트 정의서
- 브라우저 저장 기반 진행 체크리스트
- 모바일 반응형 디자인

## GitHub Pages 게시

저장소의 `Settings → Pages`에서 다음과 같이 설정합니다.

- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

저장 후 GitHub Pages 주소가 생성됩니다.
